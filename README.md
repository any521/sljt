# 阿卡姆号 / Arkham

> 科幻克苏鲁**卡牌构筑 Roguelite**（Deckbuilder Roguelite）· PC / Steam · Godot 4.6

一艘名为「阿卡姆号」的空间站被一团来自深空的黏块撞穿。那团东西带来的组织是活的、湿的、有机的。
主角被感染了右手，但他还在硬撑。

> **一句话定调**：一个真实、冰冷、有磨损的人造空间站，正在被一种有机的、湿的、不该存在的东西从内部吞掉。

## 快速开始

**环境要求**

| 项 | 版本 |
|---|---|
| Godot | **4.6 stable**（标准版即可，无需 .NET） |
| 系统 | Windows / macOS / Linux |

**运行**

\`\`\`bash
# 图形界面运行
godot --path .

# 或者用 Godot 编辑器打开 project.godot 后按 F5
\`\`\`

**首次导入**（新增/移动过素材后必须执行一次，否则资源会静默走 fallback）

\`\`\`bash
godot --headless --path . --import
\`\`\`

## 操作方式

| 操作 | 行为 |
|---|---|
| **点击手牌** | 牌原地向上抬出 1/4 屏高并固定，指向箭头连到光标 |
| **再点同一张** | 取消拾起，牌回手牌 |
| **把光标移到目标上** | 箭头变亮 + 目标出现准星 |
| **点击目标** | 该牌入队释放，播放队列/飞行/命中特效后按机制结算 |
| **按住拖动** | 进入拖拽模式（此时隐藏系统光标，箭头即光标；进入出牌区切到中央停放点） |
| **右键 / Esc** | 取消 |
| **1~9 / 0** | 选中对应手牌 |
| **Tab** | 切换目标 |
| **Enter** | 对当前目标打出已选牌 |
| **空格** | 结束回合 |

> 出牌区是**自适应**的：手牌贴底时要向上拖够远才触发，手牌位置高时不必拖那么远。
> 牌打出后先进**出牌队列**排队；轮到它时若已不满足条件（例如能量被前面的牌花掉），自动放回手牌。

## 项目结构

\`\`\`
src/
  core/        纯逻辑层（禁止依赖任何 UI/场景）：战斗总控、伤害管线、回声、隔离值
  data/        卡牌 / 敌人静态定义
  autoload/    卡池、卡面资源
  ui/          表现层：战斗视图、卡牌控件、托盘、特效
    effects/   表现总控（粒子池、屏幕特效）与着色器
    widgets/   卡牌 / 托盘 / 四角金饰 / 指向箭头 / 准星 / 像素框
scenes/        场景与预制体（卡牌、角色、战斗世界、HUD、特效）
assets/        美术、音频、字体、主题
tests/         回归测试与截图脚本（无头可跑）
tools/         素材处理工具（降采样、白底抠图等）
docs/          设计与规范文档（见下）
\`\`\`

## 测试

全部为**无头可跑**的脚本测试，无需人工操作。推荐按顺序执行：

\`\`\`bash
GODOT="godot"   # 换成你的 Godot 可执行文件路径

# 核心逻辑（112 项）
$GODOT --headless --path . --script res://tests/test_combat.gd

# 回合循环 / 补牌回归（6 回合）
$GODOT --headless --path . --script res://tests/test_turn_loop.gd

# 表现集成（51 项）
$GODOT --headless --path . --script res://tests/test_presentation.gd

# 交互与版式（会顺带生成截图到 artifacts/verification/）
$GODOT --path . --script res://tests/verify_hand_layout.gd      # 1~10 张：居中 / 不出框 / 不遮挡
$GODOT --path . --script res://tests/verify_card_interaction.gd # 悬停 / 瞄准 / 队列停放
$GODOT --path . --script res://tests/verify_click_flow.gd       # 点击拾起 → 取消 → 点目标释放
$GODOT --path . --script res://tests/verify_play_queue.gd       # 非阻塞队列 + 条件不足自动回手
$GODOT --path . --script res://tests/verify_mouse_drag.gd       # 真实拖拽路径（含中心停放）
\`\`\`

**注意**：改动脚本后先跑一次 \`--import\` 再跑 \`--script\`，否则类别名缓存失效会报一堆假错误。

## 素材管线

AI 生成的素材通常有两个坑：**2048 级大图**与**白底不透明**。项目内提供两个工具处理：

\`\`\`bash
# 1/8 最近邻降采样（保留像素网格）
$GODOT --path . --script res://tools/downscale_tray.gd

# 白底软抠图：硬白→全透明，边缘灰白→半透明过渡，不留白色光晕
$GODOT --path . --script res://tools/key_white_tray.gd
\`\`\`

处理目标写在两个脚本顶部的 \`JOBS\` 常量里，新增素材只需加一行。
运行时贴图必须开 **最近邻过滤**（\`TEXTURE_FILTER_NEAREST\`），否则像素格会被插值糊掉。

## 开发规则

以下两条是**硬约束**，Code Review 直接打回：

1. **美术**：任何新资产必须先对照 [美术基调](docs/阿卡姆号-美术基调-v1.0.md) 取色，
   且**生成后先给制作人过目**，通过才接入游戏。
2. **代码**：禁止运行时 \`Node.new()\` / 自定义脚本 \`.new()\` 造节点；
   重复生成的物体一律做成 \`.tscn\` 预制体，用 \`@export var xxx_prefab: PackedScene\`
   在编辑器里拖拽赋值（详见 [预制体规范](docs/项目规则-预制体规范.md)）。

提交信息建议用 \`类型(范围): 说明\` 的形式，例如
\`feat(combat): 出牌队列支持条件不足自动回手\`、\`fix(ui): 手牌按卡槽中心对齐\`。
