## 三、目标资产规格（关键）

### 3.1 这是「小人儿」，不是「立绘」

**请注意区分这两个概念：**

| | 立绘（不要） | **小人儿（要的就是这个）** |
|---|---|---|
| 尺寸 | 大，半身或胸像 | **小，约 64×64** |
| 内容 | 头部到大腿 | **完整全身，从头到脚** |
| 用途 | 界面展示、卡牌头像 | **游戏场景和战斗界面里站着的那个人** |
| 细节 | 丰富，画脸画表情画材质 | **极度精简，靠剪影和色块** |
| 参考 | 角色美术设定图 | 《死亡细胞》《星露谷》《泰拉瑞亚》里的小角色 |

### 3.2 技术规格

| 项 | 要求 |
|---|---|
| **最终使用尺寸** | **64×64 像素** |
| 生成输出尺寸 | 建议 1024×1024（正方形，1:1，不允许拉伸） |
| 像素密度 | 按「64×64 像素画放大 16 倍」的标准 |
| 色数 | **不超过 16 色** |
| 画法 | 硬边像素画，每格像素大小一致，**严禁抗锯齿/模糊/渐变** |
| 背景 | 纯深色（接近黑），便于抠图 |
| 禁止 | 文字、数字、水印、边框 |

### 3.3 帧数需求

| 帧 | 姿势 | 用途 |
|---|---|---|
| 1 | 待机（站立） | 默认状态 |
| 2 | 行走 | 场景移动 |
| 3 | 攻击（右手爪向前挥出） | 战斗出牌 |
| 4 | 受击（身体后仰） | 受伤 |

**每一帧都是完整的独立图，不是动画序列图。**

## 五、⚠️ 像素预算（请仔细阅读，这决定了提示词该怎么写）

这是**之前所有尝试失败的根本原因**。请认真理解这组数据：

### 5.1 64×64 下能分到多少像素

| 部位 | 像素预算 |
|---|---|
| 全身高度 | 约 **60 px** |
| 头部（含头发） | 约 **10 px** |
| **脸** | 约 **8×8 px** |
| 每只眼睛 | **1–2 px** |
| 嘴 | 1 px 或没有 |
| 躯干 | 约 20 px 高 |
| 双腿 | 约 20 px |

### 5.2 因此，以下细节**画了也会糊，必须明确禁止**

- ❌ 脸上的疤痕
- ❌ 装甲上的面板、指示灯阵列、铆钉、螺丝
- ❌ 腰带上挂的三个工具
- ❌ 装甲缝隙的纹理、划痕、接缝线
- ❌ 复杂的机甲结构分层
- ❌ 手指的细节

### 5.3 允许画的内容（只有这些）

| 类别 | 内容 |
|---|---|
| **剪影** | 头、身体、两条腿、两条手臂的形状 |
| **大色块** | 深色装甲（大面积平涂）、肤色（脸和左手）、**品红右手（焦点）** |
| **1–2 个特征点** | 只够放**一个**辨识标志（建议：胸口 1 像素的冷青指示灯） |

### 5.4 ★ 核心原则

> **全身只允许有一个视觉焦点：那只品红色的右手。**
> 它必须比身上任何其他地方都亮、都饱和。
> 其他所有细节都必须砍掉。

**提示词里应该明确写出"不许画什么"**，而不只是写"要画什么"。

## 六、之前尝试过的方法与失败原因（避免重复踩坑）

| 尝试 | 方法 | 结果 | 失败原因 |
|---|---|---|---|
| **1** | AI 生成（豆包）**半身立绘**提示词 | ❌ 失败 | 方向错了，用户要的是小人儿不是立绘 |
| **2** | AI 生成（豆包）**小人儿**提示词 | ❌ 失败 | 提示词里堆了 20+ 个细节，60px 高的小人放不下 |
| **3** | AI 生成**减少细节后**的提示词 | ❌ 用户生不出图 | **根本问题：AI 出的是 1024×1024 插画，不是 64×64 像素网格，缩下去必糊** |
| **4** | 程序化绘制（用 Aseprite Lua 脚本按坐标画） | ⚠️ 能出图但不好看 | 程序化能画对结构，但**没有审美判断**，画不出好的像素画 |

### 关键结论

> **64×64 的像素小人儿，本质上必须"在网格上一格一格画"**，这是像素画的核心工作方式。
> AI 图像生成模型**不擅长这个**——它们擅长出大尺寸插画。

### 因此请你思考

在撰写提示词时，请考虑以下哪种策略更有效：

- **策略 A**：让 AI 出一张**大尺寸的角色概念设计图**（非像素画），作为人工描摹的参考
- **策略 B**：设计一个提示词，**明确要求 AI 按 64×64 的网格逻辑作画**（像素块大而清晰），而不是出高清插画
- **策略 C**：让 AI 生成**像素化的角色三视图**，明确像素块尺寸统一

**请你在提示词中明确选择一种策略，并说明理由。**

## 七、美术风格参考

### 7.1 像素科幻的气质

> **"像素科幻"的高级感来自克制，不来自高科技炫光。**
>
> - **暗**：大面积是深色，光只出现在需要的地方
> - **小**：指示灯就是 1–2 个像素，不是一片光晕
> - **整**：结构线横平竖直，符合工程逻辑
> - **旧**：边缘有磨损、划痕、锈迹

### 7.2 可参考的游戏

| 《死亡细胞》 | 小型角色像素精灵的读图性 |

| 《FTL：超越光速》 | 极简像素科幻 |
| 《潜渊症》Barotrauma | 空间站内部，冷硬工业感 |
