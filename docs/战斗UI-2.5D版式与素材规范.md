# 《阿卡姆号》战斗 UI：2.5D 版式与素材规范

## 1. 这版解决的问题

战斗画面的视觉主体改为真实 3D 舱室、角色站位和光影。UI 只承担信息与操作，不再用大面积面板占据舞台。

- 主角与宋梅都放在 3D 世界里，脚底接触地面并接收投影。
- 主角屏幕高度控制在画面高度的 14%～16%，宋梅为 11%～13%，敌人为 15%～18%。
- 摄像机使用接近正面的轻俯视视角，建议俯角 10°～14°，水平偏角 4°～8°。
- 中央 `x=360..1560, y=160..810` 是 3D 战斗安全区，不放常驻大面板。
- 手牌只占底部，默认卡牌约 `148×210`，悬停才抬高、放大和显示详细描述。

## 2. 1920×1080 布局

| 元素 | 参考区域 | 规则 |
|---|---:|---|
| 舰桥状态轨 | `x=40, y=22, w=1840, h=42` | 细线式结构，只放回合、舱段和菜单入口 |
| 回响链 / 隔离值 | `x=674, y=68, w=572, h=83` | 共用一个紧凑诊断仪，不做横跨全屏的顶栏 |
| 宋梅状态 | `x=47, y=739, w=298, h=72` | 只显示头像、姓名、生命和关键状态；人物本体仍在场景里 |
| 玩家状态 | `x=35, y=830, w=430, h=135` | 左下角驾驶仪式组件，避免与手牌争夺中心区域 |
| 手牌槽 | `x=455, y=813, w=1010, h=267` | 底边嵌入式卡槽；未选中卡牌不超过舞台地平线 |
| 牌库 / 弃牌 | `x=1522..1813, y=824, h=30` | 用小型计数器，不使用独立大面板 |
| 结束回合 | `x=1512, y=869, w=360, h=152` | 唯一常驻高亮操作；琥珀色表示可执行 |
| 敌人血条 / 意图 | 世界坐标投影 | 跟随敌人头顶，受摄像机与遮挡规则约束 |

## 3. 3D 场景预留

战斗场景后续使用 `Node3D` 根节点搭建，UI 保持在独立 `CanvasLayer`。推荐结构：

```text
CombatRoot
├── World3D
│   ├── CameraRig
│   │   └── Camera3D
│   ├── DeckGeometry
│   ├── PlayerAnchor
│   ├── CompanionAnchor
│   ├── EnemyAnchors
│   ├── DirectionalLight3D
│   ├── PracticalLights
│   └── WorldEnvironment
├── WorldFx
└── BattleHud (CanvasLayer)
```

- 主光来自左上方冷青色灯带，角色和敌人必须有可读的投影。
- 右后方使用弱琥珀轮廓光分离人物，异变区域只允许少量洋红色反射。
- 地面要有透视线、舱板接缝与局部反射，以明确 2.5D 空间关系。
- 宋梅站在主角后左侧；她不是 HUD 头像替代物。头像只用于快速读数。
- 敌人血条与意图通过 `Camera3D.unproject_position()` 转成屏幕坐标，再交给 HUD 层显示。

## 4. 视觉语言

UI 代表人类秩序，统一使用硬表面工程造型：切角、铆钉、刻度、仪表槽和少量磨损。怪物的有机形态只存在于 3D 世界、卡图与命中特效中，不侵入 UI 边框。

- 基底：`#0A0E14`、`#111620`
- 结构：`#1E3A52`、`#3A82B2`
- 信息与选中：`#6BC7FF`、`#B2E8FF`
- 可操作：`#E8A830`、`#FFDC82`
- 危险：`#D64440`
- 异变：`#C7479E`，只用于异常状态和世界污染

组件 SVG 具有透明背景，可直接作为 Godot `Texture2D` 使用。面板类素材应在导入后配置为 `NinePatchRect`；建议切片边距如下：

| 素材 | 左 | 上 | 右 | 下 |
|---|---:|---:|---:|---:|
| 玩家状态框 | 32 | 24 | 32 | 24 |
| 宋梅状态框 | 22 | 18 | 22 | 18 |
| 敌人血条 | 20 | 14 | 20 | 14 |
| 卡槽 | 64 | 40 | 64 | 40 |
| 提示框 | 32 | 28 | 32 | 28 |

所有文字、数值、血量填充与动态亮度由 Godot 绘制，素材只提供结构和固定装饰。这能避免生成图中文字失真，也方便无障碍模式、分辨率缩放和本地化。
