# 《阿卡姆号》场景节点结构与编辑指南

本项目的可视对象以 `.tscn` 场景维护。角色、卡牌、灯光和主要界面层都能在 Godot 编辑器中单独打开和修改，不需要到脚本里寻找绘制代码。

## 1. 入口与战斗场景

`main.tscn` 中的实例已启用“可编辑子节点”。需要长期复用的修改，仍建议双击场景图标打开对应的原始 `.tscn`，避免只改到某一个实例。

## 2. 修改主角二技能序列帧

1. 在文件系统中打开 `scenes/actors/shen_ming.tscn`。
2. 选择 `ShenMing/AnimatedSprite2D`。
3. 在底部 `SpriteFrames` 面板切换到 `draw_gun`。
4. 可以拖入、删除、排序 12 帧，也可以修改播放速度和循环设置。
5. `ShenMing` 根节点的 `attack_animation` 当前设为 `draw_gun`。工程攻击牌会先完整播放该动画，再对敌人结算伤害，最后自动回到 `idle`。

二技能图集位于 `assets/art/characters/shen_mingyan/battle_skill_2_512x384.png`。当前按 4 列、3 行、每格 128×128 切分。

## 3. 修改角色与站位

- 单个角色的缩放与动画：打开 `scenes/actors/` 下对应场景，选择其中的 `AnimatedSprite2D`。
- 战场站位：打开 `scenes/battle_world_2d.tscn`，移动 `Gameplay/Actors` 下的角色实例。
- 新敌人的运行时表现仍由逻辑数据驱动；外观应先做成独立角色场景，再实例化到 `Actors`。

角色根节点的矩形也是拖牌命中区域。调整角色尺寸后，应同时确认运行时点击和拖牌判定。

## 4. 修改卡牌节点

打开 `scenes/widgets/battle_card.tscn`：

- `Frame`：卡框 PNG。
- `Art`：卡面插画。
- `Cost`、`Name`、`Index`、`Type`、`Description`、`Badge`：文字节点。
- `Dim`：不可用状态遮罩。

运行时每张手牌都是该场景的实例，挂在 `Cards/Hand` 下。卡牌的数据内容由脚本填充，节点布局、字体、尺寸和贴图可在场景中修改。

## 5. 修改船员状态栏与字体

- 沈明和宋梅的状态栏来自 `scenes/widgets/crew_status_panel.tscn`，两个实例分别位于 `battle_hud.tscn` 的 `PlayerStatus/ShenMingStatus` 与 `CompanionStatus/SongMeiStatus`。
- 沈明正式立绘位于 `assets/art/characters/shen_mingyan/portrait_shen_ming.png`。HUD 通过 `AtlasTexture` 裁取头肩区域，裁切框可在 `ShenMingStatus` 的 `portrait_texture` 子资源中修改。
- 全局字体主题位于 `assets/themes/pixel_font_theme.tres`，字体文件为 `字体/[可商用]Z 工坊像素黑体 12px/ZLabsPixel_12px_M_CN.ttf`。战斗界面的 Label、Button 和 RichTextLabel 会统一继承该主题。
- 战斗 UI 的框体由 `src/ui/widgets/pixel_frame.gd` 在固定 4×4 屏幕像素网格上绘制，与角色放大后的单个像素尺寸一致；不再依赖旧的平滑 SVG 框体。
- 调整字体大小后，应在 1920×1080 运行窗口检查名称、生命值、敌人意图、牌堆按钮和结束回合按钮是否被裁切。

## 6. 灯光与体积光

打开 `scenes/environment/battle_lighting.tscn`：

- `CanvasTone` 控制整张 2D 画面的环境色。
- `PracticalLights` 下是可移动的 `PointLight2D`。位置、颜色、能量和范围都能在检查器调整。
- `Atmosphere/VolumetricBeams` 使用 `volumetric_beams.gdshader`，材质参数可调整光束颜色、强度、宽度、角度、衰减和漂移速度。
- `Atmosphere/Fog` 使用 `atmosphere_fog.gdshader`，可调整雾色、密度和漂移速度。

当前是 2D 项目，所以这里的“体积光”是屏幕空间光束 Shader。若以后把战场升级为 `Node3D`，再使用 `WorldEnvironment`、雾体积和 3D 灯光；HUD、Cards、Overlays 可以继续作为独立 Canvas 层保留。

## 7. 防止覆盖手工修改

`tools/generate_editable_scenes.gd` 是一次性的场景搭建工具，现在默认拒绝运行，避免覆盖编辑器中的手工修改。确实需要从素材重新生成全部角色和卡牌场景时，先设置环境变量 `ARKHAM_REBUILD_EDITABLE_SCENES=1`，并确认已备份场景文件。
