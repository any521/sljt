# 《阿卡姆号》美术基调 v1.0

> **本文档是硬约束。** 此后生成任何美术资产（卡面、卡框、敌人、UI、场景）都必须先对照本文档，
> 颜色、画布、光照、构图不得偏离。新增资产需先按 §7 流程给制作人过目，通过后才可接入游戏。

---

## 0. 一句话定调

> **一个真实、冰冷、有磨损的人造空间站，正在被一种有机的、湿的、不该存在的东西从内部吞掉。**
>
> 画面上的所有张力都来自这一个对比：**硬与软、直与弯、冷与暖、干净与腐败。**

---

## 1. 两条美术路线 `[锁定]`

本作只有两条路线，**不存在第三条**。每张资产必须明确属于其中一条。

| | **路线 A：工程系** | **路线 B：异化系** |
|---|---|---|
| **对应归属** | 规程（工程卡） | 异化（变异卡） |
| **叙事** | 人类造物的遗迹 | 星之黏块带来的东西 |
| **气质** | 硬、冷、精准、功能主义 | 软、湿、不规则、有生命 |
| **形状语言** | 直线、直角、几何体、对称 | 曲线、螺旋、不对称、有机 |
| **质感** | 金属、哑光塑料、玻璃、磨损涂层 | 黏膜、软骨、甲壳、生物荧光 |
| **动势** | 静止、稳定、锁定 | 蠕动、膨胀、生长 |
| **光线** | 点光源、硬阴影、屏幕发光 | 自发光、辉光扩散、无明确光源 |

**中立（回复卡）走 A 的简化版**：同样是几何与直线，但去掉科技感，偏"医疗/工具"的中性灰蓝。

## 3. 工程系详细风格规范

### 3.1 必须出现的元素（选 2–3 个）

- **功能指示**：刻度、指示灯、状态条、数值标记
- **结构件**：螺栓、焊缝、加固肋、铰链、钳口
- **线缆/管路**：直线走线，转角处规整
- **屏幕/面板**：发光的矩形显示区，内部有抽象数据图形
- **工业标识**：条纹、方格、编号、箭头指向

### 3.2 质感要求

> **关键：不能太干净。** 空间站已经在轨运行很久，一切都要有**使用痕迹**。

- 边缘要有磨损（亮色描边断续，不是完整一圈）
- 金属面要有**轻微的划痕**（1–2 像素的浅色短线）
- 角落允许有**锈斑或污渍**（用暗部色做 1–2 像素点缀）
- **禁止**：崭新发亮的塑料感、糖果色、卡通描边

### 3.3 构图

- **正面平视**为主，不做透视
- 主体占画布 **60–70%**，留出呼吸空间
- **对称优先**，但允许轻微偏移（3:2 或 2:1 的视觉重量分配）

### 3.4 光照

- 单一主光源，方向为**左上打光**（全局统一）
- 暗部不用纯黑，用 `#111620`
- 发光元素（屏幕、指示灯）周围要有 **1–2 像素的辉光扩散**

## 4. 异化系详细风格规范

### 4.1 必须出现的元素（选 2–3 个）

- **有机体**：膜、腔体、触须、软骨、甲壳节
- **眼**：单眼、多眼、盲眼（眼是最强的克苏鲁符号）
- **血管/脉络**：分叉的线状结构，有粗细变化
- **发光组织**：生物荧光点、孢子、脉动的光斑
- **孔洞/开口**：不该有的洞，边缘是湿的

### 4.2 质感要求

> **关键：要"湿"。** 异化系的一切都该看起来像刚从什么东西体内取出来的。

- 必须有 **1–3 个高光点**表现湿润（用 `#F0F6FA` 单像素）
- 组织表面用**渐变抖动（dithering）**表现肉的层次，不要平涂
- 边缘是**不规则的**——不允许出现直线或规整的圆
- **禁止**：干净的几何形、对称结构、清晰的机械零件

### 4.3 构图

- **不对称**是铁律。左右视觉重量必须是 3:2 或更偏
- 可以有**部分出画**（组织延伸到画布外，暗示"它比画面更大"）
- **主体占 70–80%**，比工程系更满、更有压迫感

### 4.4 光照

- **无明确主光源**——光是组织自己发出来的（自发光）
- 允许逆光轮廓（边缘亮，中心暗）表现透明感
- 整体对比度比工程系**更低**，营造"糊成一团"的感觉

## 5. 两条路线的交界规则

**当一张图同时包含两者时（如卡框 + 异化卡面）：**

| 位置 | 用哪条路线 |
|---|---|
| 卡框 / UI / 文字 | **永远是 A**（哪怕卡牌是异化系） |
| 卡面插画 | 依卡牌归属决定 |
| 交界处 | **工程系在外、异化系在内**——人造物被从内部撑开 |

> **这条规则的意思是**：UI 永远保持"人类造物"的冷硬，让异化的部分显得**更突兀**。
> **人是秩序，它们是无序。UI 是人的最后一道防线。**


```
pixel art, 9-slice card frame, 103x143, sci-fi industrial UI panel,

corner brackets, thin border, beveled edges,
cyan accent (#3A82B2), slight wear on edges,
flat pixel style, no gradients, no texture noise
```

### 6.4 敌人立绘（工程化眷族：两条路线的混合体）

```
pixel art, 64x64, lovecraftian creature that was once human or machine,
hybrid of sci-fi suit and organic growth, magenta and cyan accents,
asymmetric silhouette, wet organic parts bursting through metal,
no straight lines on the organic parts, sharp lines on the metal parts,
dark background, menacing, body horror
```

> **敌人的核心视觉命题**：**金属还在，但被从里面撑开了。**
> 这是本作最好用的一个视觉母题——宇航服还穿着，但头盔里已经不是人了。

**每次生成新美术，必须走完这五步：**

| 步骤 | 内容 | 谁做 |
|---|---|---|

> ⚠️ **第 3 步是硬性要求。** 制作人明确要求："画完之后先给我打开，不行了就改，不能画完后直接就加到游戏里。"

## 8. 常见错误清单（避免）

| ❌ 错误 | ✅ 正确 |
|---|---|
| 工程系画得太干净、太新 | 加磨损、划痕、锈斑 |
| 异化系画成对称的 | 强制不对称，允许出画 |
| 用纯黑 `#000000` 做暗部 | 用 `#111620`（A）/ `#1A0818`（B） |
| 平涂色块，没有层次 | 用抖动（dithering）做渐变 |
| 异化系有直线或正圆 | 边缘必须不规则 |
| 引入色板外的颜色 | 严格查 §2 色板 |
| 两个光源方向不一致 | 全局统一左上打光（异化系除外，用自发光） |
| 异化系画成血腥猎奇 | 是**身体恐怖**，不是血浆片。要"不对劲"而不是"恶心" |
