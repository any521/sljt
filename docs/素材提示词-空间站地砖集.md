# 《阿卡姆号》素材提示词：空间站地砖集（8×4 / 32 格）

> 对照 `docs/阿卡姆号-美术基调-v1.0.md`（硬约束）改写。
> 用途：生成**可直接裁剪**的俯视角地砖集，供战斗场景地面层使用。
> 生成后按 §7 流程：**先给制作人过目**，通过后才接入游戏。

---

## 一、可直接复制的提示词（中文，主提示词）

\`\`\`
像素游戏瓦片集素材图，俯视视角（正投影，无透视），科幻空间站室内地砖，
主题：阿卡姆号空间站的「居住舱」走廊与舱室地面，含轻度生物感染区。
复古像素游戏美术风格，Aseprite 硬边像素质感，有限调色板，
清晰锐利的方块边缘，无抗锯齿，无模糊，无平滑渐变，无柔化阴影。

【画布与网格】完整一张瓦片集大图，规则网格 8 列 × 4 行，共 32 个瓦片，全部平铺在同一张图中。
网格之间不留空隙、不留外边距，所有瓦片边缘像素严格对齐，每个瓦片是正方形，尺寸完全统一。
画布 1024 × 512，每格 128 × 128，像素粒度 4 × 4（每个"美术像素"在图上占 4×4 的纯色方块）。
不要画出网格线，不要画出瓦片之间的分割缝。

【色彩】严格使用《阿卡姆号》锁定色板，不引入色板外的颜色，总色数不超过 32 色。
冷金属主色系：最深阴影 #0A0E14、暗部 #111620、结构暗面 #1E3A52、金属受光 #3A82B2。
屏幕与指示灯：亮部 #6BC7FF、高光 #B2E8FF（只在发光元素与边缘光上小面积使用）。
暖色点缀：警示 #E8A830、核心高光 #FFDC82（仅用于标识与能量件，占比很小）。
危险色 #D64440 只在过载标记上零星出现。
生物感染（克制使用）：组织暗部 #1A0818、肉暗面 #48123A、组织主体 #8C2A70、
膜与血管 #C7479E、黏膜反光 #FF9EDC、湿滑高光 #F0F6FA（单像素）。
暗部禁止使用纯黑 #000000，一律用 #111620（工程）或 #1A0818（感染）。

【光照】全局统一：单一主光源来自左上方，硬阴影，暗部用色板里的暗部色，不用纯黑。
发光元素（指示灯、屏幕、生物荧光）周围允许 1–2 像素的辉光扩散，扩散必须是离散像素而非模糊。

【质感要求】空间站已在轨运行很久，一切都要有使用痕迹：
边缘磨损（断续的亮色描边，不是完整一圈）、1–2 像素的浅色划痕、
角落允许 1–2 像素锈斑或污渍。禁止崭新发亮的塑料感、禁止糖果色、禁止卡通描边。

【感染表现（克制）】感染只以"星之黏块"的痕迹出现：黏液薄痕、滴挂、细小血肉组织纹理、
组织从舱板缝隙里挤出的边缘。感染区域内部形态**不规则、不对称、无直线无正圆**，
但瓦片四边必须按网格收口，由工程系金属边压住 —— 遵循"工程系在外、异化系在内"的交界规则。
不要出现完整怪物、不要出现任何角色、不要出现眼睛以外的具象器官、不要出现大面积血腥。

【禁止】文字、数字、水印、签名、边框、外框、人物、怪物、载具、道具摆件、
透视、等距投影、镜头畸变、抗锯齿、模糊、噪点、渐变过渡、柔化阴影、柔光、辉光模糊、
色板外颜色、纯黑、白色描边、整格高光、重复的镜像对称装饰。

【版式】横排连续网格，按"行"分组：第 1 行完好工程地砖，第 2 行磨损与破损地砖，
第 3 行感染地砖（污染度从左到右递增），第 4 行边缘与墙角过渡件。
每个瓦片必须是可平铺件：不出现只属于单格中心的装饰性图案，接缝处不要有独立的深色描边。
\`\`\`

## 四、负面清单（生成后逐条核对）

| ❌ 出现即废 | 说明 |
|---|---|
| 抗锯齿 / 模糊 / 平滑渐变 | 像素必须硬边；感染系的层次用**抖动**，不是渐变 |
| 柔化阴影 / 辉光模糊 | 阴影用色板暗部色块，辉光用离散像素扩散 |
| 纯黑 #000000 作暗部 | 工程用 #111620，感染用 #1A0818 |
| 色板外颜色 | 逐格取色核对 §一 的色值 |
| 文字 / 数字 / 水印 / 边框 | 一格都不允许 |
| 人物 / 怪物 / 道具摆件 | 感染只表现"组织的痕迹"，不出现完整生物 |
| 透视 / 等距投影 | 必须是正投影俯视 |
| 瓦片间空隙 / 外边距 / 网格线 | 32 格必须像素紧贴 |
| 只属于单格中心的装饰图案 | 会破坏平铺，必须避免 |
| 感染格内部出现直线或正圆 | 内部必须不规则（外部按网格收口是允许且要求的） |

## 五、后期处理与接入

1. **缩放**：生成稿 1024×512 → 用**最近邻（Nearest Neighbor）**缩放到 **256×128**，
   得到真正的 32×32 瓦片。禁用双线性/双三次。
2. **切片**：Aseprite 里用 `Sprite → Grid` 设 32×32，再 `File → Export Sprite Sheet`；
   或直接在代码里按 `region = Rect2(col * 32, row * 32, 32, 32)` 切。
3. **命名**：按 §三 的表格命名（`deck_plate_plain` 等），便于代码引用。
4. **平铺校验**：把同一张瓦片 3×3 拼一遍，检查接缝处有无"深色描边"或重复图案。
5. **接入**：先只做地面层，挂在战斗场景的背景之下；**通过制作人复核后**再写进场景。
6. **色板校验**：把成品颜色与 §一 的色值逐个比对，出现色板外颜色就回炉。

## 六、与原始提示词的差异（改了什么、为什么）

| 原始写法 | 改成 | 原因 |
|---|---|---|
| 冷灰金属、深灰、暗银 | 映射到 A 路线结构色 #111620 / #1E3A52 / #3A82B2 | 项目色板**锁定 32 色**，不含独立中性灰；直接写"暗银"会引入色板外颜色 |
| 暗紫红、蓝紫色感染 | B 路线 #1A0818 / #48123A / #8C2A70 / #C7479E / #FF9EDC | 同上，且要"克制" |
| "无渐变" | 保留，但补充：感染系允许**抖动** | 美术基调 §4.2 要求异化系用 dithering 表现肉的层次，与"禁渐变"不冲突 |
| 未指定光照 | 补充"全局左上单一主光源、硬阴影" | 美术基调 §3.4 全局统一 |
| 未指定画布尺寸 | 1024×512 + 4×4 像素粒度 → 最近邻降到 256×128 | AI 直接出 256×128 必然糊；4 倍稿再降采样是像素风的标准做法 |
| 32 格内容只列了类别 | 展开成 §三 的 32 格命名表 | 可直接用于切片命名与代码引用 |
| "边缘像素严格对齐" | 升级为**可平铺**要求（无独立描边、无单格中心图案） | 地砖集的核心是能拼，不只是对齐 |
| 未提交互/流程 | 补 §7 流程：先给制作人过目 | 美术基调 §7 硬性要求 |
