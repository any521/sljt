# 《阿卡姆号》素材提示词：可扩展牌框（九宫格金饰镶嵌）

> 对照 `docs/阿卡姆号-美术基调-v1.0.md`（硬约束）与 `docs/素材提示词-空间站地砖集.md` 的规格。
> 目标：生成**可在游戏里任意拉伸**的牌框/托槽边框素材，四角为繁复镶嵌装饰。
> 生成后按基调 §7：**先给制作人过目**，通过后才接入。

---

## 〇、三条决定生成方式的前提（先看这里）

1. **可扩展 = 九宫格**：四角固定不拉伸，四条边可重复/镜像，中心区域可任意拉伸。
   所以边条上**不能出现只此一处的独立花纹**，否则拉伸后会被拉长变形。
2. **中心必须完全透明**：游戏里的托槽内衬是半透明的蓝，卡牌压在框里。
   框图只画"边框本身"，中心一个像素都不许画。
3. **像素风 + 4 倍稿**：直接出 192×192 必然糊。出 **768×768**（每格 256×256，
   像素粒度 4×4），后期用**最近邻**降到 192×192。

---

## 一、主提示词：九宫格可扩展牌框（中文，直接复制）

\`\`\`
像素游戏 UI 边框素材图，科幻空间站控制台面板的镶金雕花外框，
复古像素美术风格，Aseprite 硬边像素质感，有限调色板，
清晰锐利的方块边缘，无抗锯齿，无模糊，无平滑渐变，无柔化阴影。

【版式】一张正方形图，画布 768 × 768，按 3 × 3 九宫格排布，每格 256 × 256，
合计整图就是"一个完整的矩形边框"：四角 + 四条边 + 中心。
四角各占一格且必须是全图**最繁复精致**的部分：双层金线缠绕成结、结心嵌一颗亮蓝宝石、
外缘带珠饰与卷曲收口，装饰沿对角线向外铺开，四个角互为镜像对称。
四条边各占一格：由两条平行金轨夹一条亮蓝色带构成，带内是等距重复的金环镶嵌，
环内由外到内为 暗金 → 金主色 → 深蓝 → 亮蓝嵌心 → 亮金芯；
边条上的花纹必须**沿边方向等距重复、左右（上下）无缝衔接**，不得出现独立花纹。
【中心区域】完全透明，一个像素都不画。

【色彩】严格使用锁定色板，不引入色板外颜色，总色数不超过 32 色。
金色三阶：暗金 #70581C、金主色 #D6B046、亮金高光 #FFE08C（另有 #FFDC82 可用作最亮点）。
蓝色镶嵌：深蓝 #1E3A52、蓝主色 #3A82B2、亮蓝 #6BC7FF、高光 #B2E8FF。
最外层必须有 1 像素的 #0A0E14 硬描边，把金框与背景分开。
暗部不得使用纯黑 #000000。

【质感】金属要有使用痕迹：边缘断续磨损、1–2 像素浅色划痕、角内侧允许 1–2 像素污渍。
禁止崭新发亮的塑料感、禁止糖果色、禁止卡通描边、禁止整圈均匀高光。
光照统一来自左上方：同一根金线，上缘亮金、下缘暗金。

【禁止】文字、数字、水印、签名、人物、怪物、道具、图标、按钮、阴影投影、
透视、立体斜切、抗锯齿、模糊、噪点、渐变过渡、柔化阴影、辉光模糊、
色板外颜色、纯黑、白色描边、中心区域任何内容、四角之外的装饰性图案。
\`\`\`

## 二、配套提示词 A：弧形上沿编织边条（可沿弧线连续平铺）

> 手牌托槽的上沿是**扇形弧线**，矩形九宫格的直边贴不上。
> 这条专门出"能沿弧线一节一节接下去的编织边条"，用到手牌托槽顶边。

\`\`\`
像素游戏 UI 装饰边条素材图，横向长条，科幻空间站镶金雕花边条，
复古像素美术风格，Aseprite 硬边像素质感，有限调色板，无抗锯齿，无模糊，无渐变。

【版式】画布 1024 × 256，横向 8 个等宽单元，每单元 128 × 256。
边条**左右两端必须像素级无缝**：第 1 个单元的左边缘与第 8 个单元的右边缘能直接接上，
整条可以沿任意曲线一节一节连续排布而不出现断口。
每个单元内部的花纹结构一致（两条平行金轨 + 中间亮蓝色带 + 一个金环镶嵌），
金环位于单元正中，环与环之间的交叉扣线两两衔接。

【色彩】金色 #70581C / #D6B046 / #FFE08C，蓝色 #1E3A52 / #3A82B2 / #6BC7FF / #B2E8FF，
最外沿 1 像素 #0A0E14 硬描边。不使用纯黑。

【禁止】文字、水印、人物、怪物、图标、透视、抗锯齿、模糊、渐变、柔化阴影、
色板外颜色、单元内不对称花纹、两端收口造型（收口交给配套 B）。
\`\`\`

## 三、配套提示词 B：两端卷草收口件（左右各一）

> 弧线的两个端头需要有收口，否则边条像被砍断。

\`\`\`
像素游戏 UI 装饰端点素材图，正方形，画布 256 × 256，横向并排两个 128 × 256 的端点，
左侧是左端点、右侧是右端点，两者互为镜像。
造型：两条金轨端头向内卷成螺旋卷草，卷心嵌一颗亮蓝小宝石，
外缘带 2–3 粒金珠收尾，整体方向朝外张开，看起来像雕花扶手的收口。
复古像素美术风格，Aseprite 硬边像素质感，有限调色板，无抗锯齿，无模糊，无渐变。
色彩：金色 #70581C / #D6B046 / #FFE08C，蓝色 #1E3A52 / #3A82B2 / #6BC7FF，
外沿 1 像素 #0A0E14 硬描边，不使用纯黑。
禁止文字、水印、人物、怪物、透视、抗锯齿、模糊、渐变、色板外颜色。
\`\`\`

## 四、规格与切片表

| 素材 | 画布（生成稿） | 成品尺寸 | 切片方式 |
|---|---|---|---|
| 主牌框 | 768 × 768 | 192 × 192 | 3×3，每格 64×64 |
| 弧形上沿边条 | 1024 × 256 | 256 × 64 | 8 格，每格 32×64 |
| 端点收口件 | 256 × 256 | 64 × 64 | 2 格，每格 32×64 |

**主牌框的 NinePatch 边距**（Godot `NinePatchRect` 的 patch margin，按 192×192 成品算）：

| 边距 | 值 | 说明 |
|---|---|---|
| left / right | 64 | 整格四角，不参与拉伸 |
| top / bottom | 64 | 同上 |
| 可拉伸区 | 中间 64×64 | 透明区，实际由游戏画半透明蓝内衬 |

> 边条与端点件不适用 NinePatch，用"沿弧线逐节摆放"的方式接在托槽顶边：
> 中间按弧长重复边条单元，两端各接一个收口件。

## 六、负面清单（出现即废）

| ❌ | 说明 |
|---|---|
| 边条上出现独立花纹 | 拉伸/重复后会变形 |
| 中心区域有任何像素 | 会挡住卡牌与蓝内衬 |
| 四角不够繁复、与边条同密度 | 就失去了"角部重点装饰" |
| 抗锯齿 / 模糊 / 平滑渐变 | 必须硬边；明暗用离散色块 |
| 渐变代替三阶金 | 金饰必须由 暗金/金/亮金 三色分层 |
| 纯黑 `#000000` | 用 `#0A0E14` |
| 色板外颜色 | 逐格取色核对 §五 |
| 文字 / 水印 / 人物 / 怪物 / 图标 | 一律不允许 |
| 两端收口出现在边条里 | 收口只出现在配套 B 的端点件上 |
| 整圈均匀高光 | 光照必须只来自左上 |

## 七、接入与校验

1. **降采样**：768×768 → 用**最近邻**降到 192×192（禁用双线性/双三次）。
2. **校验平铺**：把边条单元左右首尾相接摆 8 次，检查接缝处有没有断口或重影；
   把主框拉伸到 2 倍宽度，检查四角有没有变形。
3. **色板比对**：成品颜色与 §五 逐个比对。
4. **接入方式**：
   - 主牌框 → Godot `NinePatchRect`，patch margin 四边各 64。
   - 上沿边条 + 端点件 → 由 `src/ui/widgets/hand_tray.gd` 沿弧线逐节摆放。
   - 素材放 `assets/art/ui/tray/`，并在对应预制体（`scenes/ui/hand_tray.tscn`）上暴露为
     `@export var frame_prefab: PackedScene` / 贴图属性，在编辑器里拖拽赋值（遵守项目预制体规范）。
5. **过目**：先给制作人看，通过后才写进场景。

## 八、相对你给的参考图，改了哪些

| 参考图做法 | 本项目改为 | 原因 |
|---|---|---|
| 内衬是暗红色嵌板 | **亮蓝镶嵌**（#3A82B2 / #6BC7FF）+ 中心透明 | 项目色板无暗红内衬；且内衬蓝由游戏半透明绘制 |
| 整体是一张固定尺寸图 | 拆成 **3×3 九宫格 + 可平铺边条 + 端点件** | 托槽宽度随手牌数量变化（1280–1400），必须能拉伸 |
| 只有四角略复杂 | **四角独立成格、密度最高**，边条只做等距重复 | 拉伸时只有四角不参与变形，重点装饰必须放这里 |
| 金饰无明显三阶 | 强制 **#70581C / #D6B046 / #FFE08C** 三阶 | 像素风里金属靠三阶分层才立得住 |
| 未规定描边 | 外沿强制 **1px #0A0E14** | 金饰叠在冷青背景上会糊；硬描边是像素风的分离手段 |
