# 第一部分 · 你要做什么

## 1.1 一句话任务

把一个**已经能玩、但表现极其简陋**的 Godot 卡牌战斗原型，**升级到接近商业级（约 80%）的视觉与手感表现**。

## 1.2 "简陋"具体指什么

| 现在有什么 | 现在**没有**什么 |
|---|---|
| 20 张卡能打 | 出牌没有飞行动画 |
| 伤害数字能算对 | 命中没有任何反馈 |
| 怪物有血条 | 怪物被打**完全不动** |
| 角色有立绘 | 立绘**不会动**（只是静态图） |
| 有战斗日志 | **没有粒子、没有震屏、没有音效** |
| 卡牌能拖拽 | 拖拽**没有任何视觉反馈** |

**你的任务就是把这些"没有"全部补上。**

## 1.3 目标质量标准

**参照对象**：《杀戮尖塔》(Slay the Spire)、《怪物火车》(Monster Train)、《欺诈之地》(Griftlands)

**具体标准**：

1. 打出一张牌 → **玩家能感觉到"打出去了"**
2. 怪物挨打 → **玩家能感觉到"打中了"**
3. 怪物打你 → **玩家能感觉到"被打疼了"**
4. 一整套连击打出来 → **有节奏感和爽感**
5. 整体看起来**不像学生作业，像能上 Steam 的小品游戏**

# 第三部分 · 爽感设计方法论（必读，这是核心）

## 3.1 核心原则：一个动作要有多层反馈

**好的打击感不是"一个特效"，而是"多层反馈同时发生"。**

以《哈迪斯》的一次普通攻击为例，**同时发生了 6 件事**：
1. 3 帧冻结（hit-stop）
2. 垂直于攻击方向的震屏（±5px）
3. 命中火花粒子（10–15 个）
4. 伤害数字弹出
5. 武器命中音效 + 敌人音效（两层）
6. 敌人受击动作

**你的每一个效果都要按这个思路设计：不是加一个粒子，而是加一组反馈。**

## 3.2 trauma 震屏模型（必须照这个实现）

**不要用 `rand()` 逐帧随机，那会产生刺耳的抖动。用 trauma 模型：**

```gdscript
# trauma 值域 [0, 1]
# 事件发生时"加"trauma，每帧"线性衰减"
# 实际抖动幅度 = trauma^2（平方会让小事件几乎不抖、大事件很猛）

var trauma := 0.0

func add_trauma(amount: float) -> void:
    trauma = minf(1.0, trauma + amount)

func _process(delta: float) -> void:
    trauma = maxf(0.0, trauma - DECAY * delta)   # DECAY = 1.0 ~ 1.5 /秒
    var shake := trauma * trauma
    # 用叠加正弦代替随机数，得到平滑的抖动
    camera.offset = Vector2(
        0.6 * sin(t * 11.0) + 0.4 * sin(t * 23.0),
        0.6 * sin(t * 13.0 + 1.7) + 0.4 * sin(t * 29.0 + 0.5)
    ) * MAX_OFFSET * shake
    camera.rotation = (0.6 * sin(t * 9.0) + 0.4 * sin(t * 19.0)) * MAX_ROLL * shake
```

**参数起点**：`MAX_OFFSET = (8..16, 6..10) px`，`MAX_ROLL = 0.05..0.12 rad`，`DECAY = 1.0..1.5`

## 3.3 缓动曲线对照表（按用途选，不要乱用）

| 用途 | Godot Tween 写法 |
|---|---|
| UI/元素**弹出** | `TRANS_BACK` + `EASE_OUT`（冲过目标再回落） |
| **落地/归位** | `TRANS_CUBIC` 或 `TRANS_QUAD` + `EASE_OUT`（减速停下） |
| **预备动作/蓄力** | `TRANS_CUBIC` + `EASE_IN`（慢慢起步然后加速） |
| **A→B 平滑移动** | `TRANS_SINE` + `EASE_IN_OUT` |
| 弹性/活泼 | `TRANS_ELASTIC` / `TRANS_BOUNCE` + `EASE_OUT`（**少用**，会显得卡通） |

**默认选择**：绝大多数"移动到某处然后停下"用 `TRANS_CUBIC + EASE_OUT`。

## 3.4 ★ 力度分级（这是不讓游戏变吵的关键）

**定义三个预设，所有效果必须归入其中一档：**

| 档位 | trauma | hit-stop | 粒子数 | 额外效果 | 对应事件 |
|---|---|---|---|---|---|
| **small** | 0.10–0.20 | 无 | 0–4 | 音效 | 悬停、抽牌、护盾 |
| **medium** | 0.30–0.50 | 0.04–0.06s | 6–12 | 白闪 | 普通攻击命中、治疗 |
| **large** | 0.70–1.00 | 0.10–0.15s | 20–40 | 白闪 + 缩放冲击 + 大伤害数字 | 暴击、连击≥4、敌人死亡、同化 |

> **铁律：不要让所有效果都拉满。** 否则玩家会疲劳，游戏会显得廉价。

## 4.1 抽牌（Draw）

**【触发】** 回合开始抽 5 张 / 卡牌效果抽牌

**【表现】**
1. 卡牌从**抽牌堆位置**（左下角，约 (80, 980)）飞出
2. 沿一条**弧线**飞到手上最终位置
3. 飞行中卡牌**从大到小**略微缩放（1.2 → 1.0）
4. 到位瞬间**轻微过冲**（TRANS_BACK）
5. 每张牌**错开 0.06s**，形成发牌的节奏感

**【参数】**
- 单张飞行时长：**0.30s**
- 缓动：`TRANS_CUBIC` + `EASE_OUT`（位置）、`TRANS_BACK` + `EASE_OUT`（到位缩放）
- 错开间隔：**0.06s**
- 力度档位：**small**（trauma 0.05，几乎不震屏）

**【素材】** 无需新素材，用现有卡框

**【实现要点】**
```gdscript
# 抽牌不要"瞬间出现在手上"。
# 应该：先在抽牌堆位置创建卡牌视觉，再用 Tween 移到目标位置。
# 关键：位置用 Path2D/曲线插值，不要直线移动 —— 弧线才有"发牌"的感觉
```

## 4.3 拖拽卡牌（Drag）

**【触发】** 左键按住卡牌

**【表现】**
1. 卡牌**放大**到 1.1 倍并**轻微旋转跟随鼠标移动方向**
2. 卡牌下方产生**虚线轨迹**或**拖尾**
3. 卡牌**投影变深**（表示"拿起来了"）
4. 手牌中**其他卡牌让开**，露出一个空位
5. 拖到怪物身上 → 怪物**描边高亮 + 脉冲呼吸**
6. 拖到空白处 → 高亮消失

**【参数】**
- 卡牌缩放：**1.1**
- 跟随鼠标：**无延迟**（1:1 跟随，不要有平滑，否则手感发飘）
- 高亮：怪物外描边 **3px**，颜色 `#6BC7FF`，呼吸周期 **0.8s**
- 力度档位：**small**

**【素材】**
- 需要一个**描边着色器**（见 §6.3）
- 可选：拖尾粒子

## 4.4 ★ 卡牌飞向目标（Card Fly）

**【触发】** 松手时鼠标在某怪物身上

**【表现】**
1. **手牌中的卡牌本身**沿一条弧线飞向怪物（不是瞬间消失）
2. 飞行中卡牌**旋转**（甩出去的动感）
3. 飞行中卡牌**缩小**并**淡出**（飞到最后只剩一个小点）
4. 卡牌**接触怪物的瞬间**才结算伤害
5. 飞行时间决定了**节奏感**——太快没感觉，太慢拖沓

**【参数】**
- 飞行时长：**0.28s**（这是关键数字，比这个快会失去重量感，慢会拖沓）
- 路径：**贝塞尔曲线**，控制点在中点上方 120px（形成抛物线）
- 旋转：从 0° 转到 **180°**（甩出去）
- 缩放：1.0 → 0.3
- 淡出：后 40% 时间内 alpha 1 → 0
- 缓动：`TRANS_QUAD` + `EASE_IN`（先慢后快，像被甩出去）
- 力度档位：**small**（飞行本身不震屏）

**【实现要点 — 关键】**
```gdscript
# ★ 不要用 Tween 的 tween_property 做弧线！要用 tween_method 手动插值

func fly_card(card: Control, from: Vector2, to: Vector2, dur: float) -> void:
    var mid := (from + to) * 0.5 + Vector2(0, -120)   # 控制点在上方
    var tw := create_tween()
    tw.tween_method(func(t: float):
        # 二次贝塞尔
        var p := from.lerp(mid, t).lerp(mid.lerp(to, t), t)
        card.position = p - card.size * 0.5
        card.rotation = deg_to_rad(t * 180.0)
        card.scale = Vector2.ONE * lerpf(1.0, 0.3, t)
        card.modulate.a = 1.0 if t < 0.6 else lerpf(1.0, 0.0, (t - 0.6) / 0.4)
    , 0.0, 1.0, dur).set_trans(Tween.TRANS_QUAD).set_ease(Tween.EASE_IN)
    await tw.finished
```

## 4.5 ★★ 命中反馈（Impact）—— 最重要的一条

**【触发】** 卡牌飞到怪物位置的瞬间

**【表现 —— 必须同时发生这 7 件事】**

| # | 效果 | 参数 |
|---|---|---|
| 1 | **hit-stop 冻结** | medium 0.05s / large 0.12s |
| 2 | **震屏** | medium trauma 0.35 / large trauma 0.8 |
| 3 | **命中粒子爆发** | medium 8–12 个 / large 25–40 个，放射状 |
| 4 | **怪物白闪** | `modulate = Color(3,3,3)` 持续 3 帧后 tween 回正常 |
| 5 | **怪物受击位移** | 沿攻击方向后退 12px，0.12s 内 `TRANS_ELASTIC` 弹回 |
| 6 | **伤害数字弹出** | 见 §4.6 |
| 7 | **命中音效** | 见 §5 |

**【参数汇总】**
```
medium（普通攻击）:
  hit_stop   = 0.05s
  trauma     = 0.35
  粒子        = 10 个
  白闪        = 3 帧
  受击位移    = 12px
large（连击≥4 / 暴击 / 击杀）:
  hit_stop   = 0.12s
  trauma     = 0.8
  粒子        = 30 个
  白闪        = 5 帧
  受击位移    = 22px
  额外        = 镜头推近 1.05× 0.15s + 屏幕色差
```

**【hit-stop 实现要点】**
```gdscript
# 用 Engine.time_scale 实现，但要小心：它会影响 UI 动画
# 更安全的做法：只在逻辑层暂停，视觉层继续跑
func hit_stop(duration: float) -> void:
    Engine.time_scale = 0.02          # 接近冻结
    await get_tree().create_timer(duration, true, false, true).timeout
    Engine.time_scale = 1.0
# 注意 create_timer 的第 4 个参数 ignore_time_scale = true —— 必须为 true，
# 否则计时器自己也被冻住了，永远不恢复
```

## 4.6 伤害数字（Damage Number）

**【触发】** 命中结算时

**【表现】**
1. 在怪物**头顶**生成数字
2. 数字**向上飘**并**放大弹出**（先放大到 1.4 倍再回落到 1.0）
3. 飘到最高点后**淡出**
4. **连击时**：数字带倍率标注，如 `12 (×1.50)`
5. **暴击/大伤害**：数字更大、颜色不同
6. 多个数字同时出现时，**水平方向随机偏移**避免重叠

**【参数】**
- 上升距离：**80px**
- 总时长：**0.9s**
- 缩放曲线：0.5 → 1.4 → 1.0（`TRANS_BACK` + `EASE_OUT`）
- 淡出：最后 0.3s
- 水平随机偏移：**±40px**
- 颜色规范：
  - 普通伤害：`#FFFFFF`（白）
  - 连击加成伤害：`#59D98C`（绿）
  - 暴击/大伤害：`#FFD23F`（金）
  - 玩家受伤：`#EB6161`（红）
  - 隔离值变化：`#C7479E`（品红）
  - 治疗：`#7FD9A0`（浅绿）
  - 格挡：`#6BC7FF`（青）
- 字号：普通 32px / 大伤害 48px

**【实现要点】**
- 数字用 `Label` + `CanvasLayer`（保证在所有元素之上）
- 用对象池复用，**不要每次 `instantiate()`**

## 4.7 怪物受击（Enemy Hit Reaction）

**【触发】** 怪物受到伤害

**【表现 — 分层】**
1. **白闪**（详见 §4.5）
2. **位移抖动**：向受击方向偏移后弹回
3. **立绘扭曲**（可选，高级）：用着色器做 0.1s 的横向拉伸
4. **血条动画**：血条不是瞬间减少，而是**有一段"虚影"缓慢追上**（表示掉了多少血）
5. **血条抖动**：血量减少时血条左右抖动 2px

**【参数】**
- 位移：12px（medium）/ 22px（large）
- 弹回缓动：`TRANS_ELASTIC` + `EASE_OUT`
- 血条虚影追及时长：**0.4s**，`TRANS_CUBIC` + `EASE_OUT`
- 血条虚影颜色：`#FF8080`

**【实现要点】**
血条要做**双层**：底层是"虚影"（延迟追赶），上层是真实血量。

## 4.13 ★ 回声连击触发（Echo Combo）—— 本作的招牌
