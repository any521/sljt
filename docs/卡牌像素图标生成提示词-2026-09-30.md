# 《拉莱耶之门》卡牌像素图标生成提示词

用途：生成可切分为 32×32 像素卡面的十格图标图集。

```text
Create a clean 5-column by 2-row sprite sheet containing exactly ten distinct square pixel-art icons for a dark science-fiction deckbuilding game. Each cell must have equal size, generous internal padding, a perfectly flat near-black navy background, and one centered symbol. Use true hard-edged pixel art with a strict low-resolution look, blocky 1-pixel clusters, no antialiasing, no blur, no gradients, no lettering, no numbers, no borders, no card frames, no characters, and no objects crossing cell boundaries. Keep silhouettes readable when reduced to 32×32 pixels. Palette: electric cyan for engineering, magenta and violet for alien mutation, with small amber highlights.

Exact cell order, left to right:
Top row:
1. Phase Register — a cyan circuit ring storing three luminous phase ticks.
2. Redundant Cache — two stacked cyan memory chips with a shield notch.
3. Memory Tumor — a magenta organic brain nodule wrapped around a tiny cyan data core.
4. Cross Calibration — two cyan targeting reticles crossing at the center.
5. Inverse Discharge — an amber energy core releasing opposing cyan bolts.

Bottom row:
6. Inhibitor Injection — a cyan injector pinning down a small magenta growth.
7. Threshold Puncture — a sharp violet tendril piercing through a cyan warning ring.
8. Rehearsal Process — a cyan looping arrow passing through two small card-like plates.
9. Sample Archive — a magenta specimen vial stored inside a cyan data bracket.
10. Hard Reboot — a cyan power switch split by a bold amber reset lightning mark.

The complete output must look like one coherent retro game UI sprite atlas. Every icon must be visually different and immediately recognizable by silhouette. Do not render any title, caption, label, grid coordinate, watermark, mockup, card border, or decorative text.
```
