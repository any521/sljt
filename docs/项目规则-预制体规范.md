# 项目规则：预制体（PackedScene）规范

> 本文件是**长期规则**，所有新增/修改代码都必须遵守。违反的写法见「禁止清单」。

## 1. 核心规则

1. **禁止运行时直接 new 节点**
   不允许 `Sprite2D.new()`、`Node2D.new()`、`Control.new()`、`Label.new()`、`ColorRect.new()`、
   以及自定义脚本类的 `.new()`（例如 `TargetingArrowScript.new()`）。
   唯一例外：**资源**对象（`StyleBoxFlat`、`ShaderMaterial`、`AtlasTexture`、`ConfigFile` 等）不属于节点，不受此限；
   但它们也优先写在场景里，方便编辑器调整。

2. **统一使用 PackedScene 预制体**
   所有**重复生成**的物体（卡牌、敌人、粒子、飘字、准星、箭头、子弹……）都必须有独立的 `.tscn` 预制文件。

3. **脚本只做三件事**
   `加载预制体 → instantiate() 实例化 → add_child() 加进场景`，
   然后设置属性、连信号、驱动动画。**不负责搭建节点结构。**

4. **用 `@export var xxx_prefab: PackedScene` 暴露预制体**
   预制体在**编辑器里拖拽赋值**（写在场景文件里），
   **禁止在代码里硬编码 `load("res://...tscn")` 路径**去取预制体。

5. **预制体必须可在编辑器里直接改**
   预制体内的节点、Sprite、动画、UI、碰撞盒，美术/策划随时双击打开就能改。
   脚本不要覆盖编辑器里配置的尺寸、pivot、颜色、字体等（不要用 `_init` 硬写这些值）。

6. **场景根节点保持简洁**
   编辑器 Local/Remote 面板里只看得到**基础节点**（容器、锚点、Camera、Light 等），
   运行时的实例一律从预制体生成。

## 2. 禁止清单（Code Review 直接打回）

| 禁止写法 | 正确写法 |
|---|---|
| `var p := ParticleGlyph.new()` | `var p: ParticleGlyph = particle_prefab.instantiate()` |
| `add_child(Label.new())` | 预制体里放好 Label，`label_prefab.instantiate()` |
| `var s := load("res://scenes/x.tscn").instantiate()` | `@export var x_prefab: PackedScene` 后 `x_prefab.instantiate()` |
| 在 `_init()` 里写 `size = ...`、`pivot_offset = ...` | 写在 `.tscn` 里，编辑器可见可改 |
| 用 `if has_node("X")` 兜底动态建节点 | 直接 `get_node("X")`，缺失就 `push_error` 报错，不静默兜底 |

## 3. 现有预制体清单与内部节点要求

### scenes/widgets/battle_card.tscn（卡牌）
根：`Control`（224×296，pivot 112,148）+ `battle_card.gd`

| 子节点 | 类型 | 作用 |
|---|---|---|
| Frame | TextureRect | 卡框底图（`pixel_frame.gd`，variant=card） |
| Art | TextureRect | 卡面窗口（运行时替换 texture） |
| Cost | Label | 左上能量数字 |
| Name | Label | 名牌条上的卡名 |
| Index | Label | 右上角手牌序号 |
| Type | Label | 类型/归属行 |
| Description | Label | 效果描述（多行，字号自适应） |
| Badge | Label | 回声预告徽标 |
| Dim | ColorRect | 不可打出时的压暗层（必须在最上层） |

### scenes/fx/particle_glyph.tscn（池化粒子）
根：`Control`（24×24，pivot 12,12）+ `particle_glyph.gd`
形状由脚本按 `kind` 在 24×24 设计框内绘制，并自动缩放到实际 `size`。
改尺寸只改这个预制体，所有粒子一起变。

### scenes/fx/ring_glyph.tscn（冲击环）
根：`Control`（size 0，绘制以自身原点为圆心）+ `ring_glyph.gd`

### scenes/fx/damage_number.tscn（伤害飘字）
根：`Label`（320×72，pivot 160,36，居中 + 描边）

### scenes/fx/sound_player.tscn（音效播放器）
根：`AudioStreamPlayer`（bus=Master）

### scenes/fx/targeting_arrow.tscn（指向箭头）
根：`Node2D` + `targeting_arrow.gd`
几何与颜色都是程序化绘制，**贴图可替换**：把 `targeting_arrow_head.png` /
`targeting_arrow_segment.png` 放进 `assets/art/ui/` 即自动切到贴图模式。

### scenes/fx/selection_reticle.tscn（目标准星）
根：`Control`（168×168）+ `selection_reticle.gd`

### scenes/widgets/thought_bubble.tscn（思考泡提示）
根：`Label`（居中 + 描边，半透明底不需要）

### scenes/ui/juice.tscn（表现层总控）
根：`Node` + `juice.gd`，导出 4 个预制体（粒子/环/飘字/音效）。

| 子节点 | 类型 | 作用 |
|---|---|---|
| PresentationFX | Control | 全屏特效容器（z=150） |
| PresentationFX/Flash | ColorRect | 全屏闪白 |
| PresentationFX/Vignette | ColorRect + ShaderMaterial | 暗角脉冲 |
| PresentationFX/Corruption | ColorRect + ShaderMaterial | 隔离值污染 |
| PresentationFX/Chromatic | ColorRect + ShaderMaterial | 色差 |
| PresentationFX/BannerBand | ColorRect | 回合横幅底带 |
| PresentationFX/Banner | Label | 回合横幅文字 |

## 5. 新增一个预制体的标准流程

1. 编辑器里新建场景，选好根节点类型，命名（如 `scenes/fx/hit_spark.tscn`）。
2. 在场景里搭好结构、调好尺寸/pivot/颜色/动画。
3. 给根节点挂脚本；脚本里只写行为，不写结构。
4. 在**宿主脚本**上加 `@export var hit_spark_prefab: PackedScene`。
5. 打开宿主场景，在检查器里把预制体**拖到该属性**上（这一步会写进 `.tscn`）。
6. 脚本里：`var fx = hit_spark_prefab.instantiate(); add_child(fx)`。
