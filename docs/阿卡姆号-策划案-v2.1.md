# 《阿卡姆号》策划案 v2.1

> 卡牌构筑 Roguelite · 克苏鲁科幻 · PC (Steam) · 单人开发
> 目标：2026 年 4–5 月抢先体验（Early Access）
> 本版变更：① 死而复生机制确定为"血肉重塑" ② 明确妹妹与主线目标 ③ 卡牌三类体系确立 ④ **开发范围收敛到第一阶段**

## 0. 一页纸

| 项 | 内容 |
|---|---|
| **游戏名** | **《阿卡姆号》**（Arkham） |
| **一句话** | 你是阿卡姆号上的操作员。星之黏块撞穿空间站，也撞进了你的身体。**空间站毁了，地球被包了三分之一，妹妹还在下面。你要回去。** |

## 2. ★ 双轨设计：物理层 + 精神层

你的指示很关键：**怪物是真的，会打你，会把你打下去；但它同时还有精神层面的作用**——就像石村号上的神印。

这两个层面必须**同时存在**，不能互相替代：

| 层面 | 表现 | 玩家感受 |
|---|---|---|
| **物理层** | 眷族真实存在，真的攻击你，真的会打死你。掉落器官、阻挡路线、成群出现 | **生存压力** |
| **精神层** | **神印**放射精神影响：往你牌堆塞「记忆碎片」、扭曲你看到的东西、改变 NPC 的样貌 | **心理压力** |

### 2.1 物理层 `[锁定]`

- 眷族会攻击、会格挡、会施加腐蚀/虚弱
- 战斗失败 = 你被打死 = 血肉重塑（见 §3）
- **尸体流进通风管与下水道 → 重组 → 以更强形态回来**

### 2.2 精神层：神印 `[锁定]`

**神印是本作精神影响的核心载体。** 它不直接攻击，它做四件事：

| 影响 | 机制表现 |
|---|---|
| **塞记忆碎片** | 往你的抽牌堆塞入负面卡「记忆碎片」，占手牌位，打出无收益 |
| **扭曲感知** | 隔离值越高，UI 越歪斜、颜色越失真、文字偶尔闪烁 |
| **篡改记录** | 你读到的日志与录音，内容会**前后矛盾**——不是 bug，是神印在改 |
| **照出内疚** | 每次神印"说话"，说的都是主角自己不愿意面对的事 |

> **「记忆碎片」的卡面内容是主角自己的过去**：他做过的某个决定、说过的某句话、辜负过的某个人。
> **为什么用卡牌表现内疚**：如果理智伤害只是掉血，那只是换皮数值。**用负面卡牌，玩家每次抽到都会被提醒一次**——机制本身就是叙事。

### 2.3 神印与眷族的关系 `[锁定]`

> **神印不制造怪物。神印让已经在场的东西醒过来。**
>
> 眷族本来就存在于空间站的每个角落（管道里、舱壁夹层里、休眠舱里），
> **是神印让它们开始动、开始聚、开始有意图。**

这条设定让"为什么一路都有敌人"变得不需要解释。

## 3. 血肉重塑：死而复生的机制

### 3.1 设定 `[锁定]`

主角是**半眷化**形态，因此拥有眷族的核心能力：**只要找到血肉，就能重塑肉身。**

- 主角死亡 → 意识保留 → **在核心区的血肉池重塑**
- 眷族被杀死 → 尸体流入通风管/下水道 → **在别处重组，以更强形态回来**
- **只有把眷族驱赶/排出船外，才能真正消灭它**

> **这条设定的作用**：它是**世界观的解释**，不是玩家的选择。
> 眷族反复出现有了正当理由，玩家不需要为此做任何决策。

### 3.2 器官：战斗资源 `[锁定]`

杀死眷族后掉落**器官**，战斗中可拾取。器官只有两个用途：

| 用途 | 说明 |
|---|---|
| **战斗奖励** | 击杀后掉落，拾取即入账 |
| **经济** | 在核心区换取卡牌 / 升级卡牌 / 购买装备 |

**器官不卡住复活，也没有隐藏后果。它是一个干净、可预期的资源。**

### 3.3 重塑无代价 `[锁定]`

**重塑不需要任何代价。死了就回核心区，重新爬。**

> **为什么这样定**：爬塔类 Roguelite 的前进驱动力**不来自"死亡有代价"，而来自"永久成长"**。
> 参考《死亡细胞》的模型：
> ```
> 死了 → 回起点 → 但这局收集的图纸/符文永久留下
>      → 下一局更强、能走更远
> ```
> **死亡不是失败，是一次资源结算。**
>
> 如果给重塑加代价，会导致**死亡螺旋**：越菜 → 死得越多 → 惩罚越重 → 更难 → 死得更多。
> 爬塔游戏必须让新手"死得起"。

### 3.4 核心张力回到战斗内部 `[锁定]`

删掉"血肉争夺"后，本作**唯一的核心张力回到战斗内部**——这反而是好事，因为它更纯粹：

> **你想打出连击 → 就必须在工程牌与异化牌之间交替 → 就必须打出异化牌 → 隔离值就涨。**
> **隔离值涨到 10 → 你被同化，这一局结束。**

**玩家每一回合都在做同一个抉择：这一下我要不要用异化牌。**
不需要跨层记忆，不需要理解隐藏因果——**压力全在这一秒。**

> **已删除**：「血肉争夺」（"你不拿器官 → 尸体重组 → 数层后回来报复"）。
> 删除理由：该机制要求玩家记住跨层的因果，且反馈不可验证——
> **玩家被打死时不会联想到"这是我三层前没捡的尸体"**。文档里听起来聪明，实际是认知噪音。
>
> **保留**：眷族尸体流入管道重组的**叙事设定**，用于解释敌人为何反复出现——
> 但它不再是玩家的选择造成的后果，纯粹是世界观背景。

### 3.5 真正的驱动力：永久成长 `[锁定]`

**每局结束后永久保留的东西**（这才是让玩家想再爬一次的引擎）：

| 类别 | 内容 |
|---|---|
| **卡组解锁** | 新卡池、新归属风格逐步开放（见 §5.2） |
| **角色成长** | 等级提升、生命/能量/手牌上限提升（老吴负责） |
| **装备** | 新装备槽位与遗物（老吴负责） |
| **剧情推进** | 每击败一个阶段 BOSS，解锁新的剧情段落与 NPC 对话 |
| **牌组构筑** | 小周解锁新的初始牌组与装扮 |

> **设计铁律**：每局结束后，玩家必须能明确说出"我这一局带回了什么"。
> 如果一局打完什么都没留下，玩家就不会再爬第二次。

## 4. 故事结构

### 4.1 开场：日常 → 断裂 `[锁定]`

**先用日常建立"正常"，再打碎它。** 那个温情的曲调必须真的存在过，断掉时玩家才会疼。

| 场景 | 内容 | 时长 |
|---|---|---|
| **日常** | 阿卡姆号区域导览（生活区 / 实验区 / 通讯区 / 工程区 / 核心区）。沈越和同事打招呼、吐槽排班、修一个坏掉的仪表 | 2–3 分钟 |
| **断裂** | **星之黏块**撞穿空间站下层。主角被击中，黏块**进入身体** | 30 秒 |
| **醒来** | 被**生物学家叶霜**救起。窗外——**地球已近三分之一被包裹** | 1 分钟 |
| **动机确立** | 二人商议：**空间站撑不了多久。得回地球。** | 30 秒 |

### 4.2 主线目标 `[锁定]`

> **回地球，见妹妹。**
>
> 不需要元叙事，不需要"我其实是第七个我"。空间站损毁、地球被包裹、妹妹在下面——**这就是全部理由**。

**但这里有一个必须让玩家慢慢意识到的矛盾**：

地球已经**被包裹了三分之一**。那"回家"到底意味着什么？妹妹所在的位置还安全吗？

> **这构成主线的核心悬念**：玩家越想回家，越会发现"家"可能已经不是一个能回的地方。
> 而主角拼命往回赶的每一步，都在让他变得更不像人——**等他到了地球，他还是那个想见妹妹的人吗？**

### 4.3 新手教程：前往通讯区 `[锁定]`

**教程的自然理由是"从当前位置走到通讯区"，不是弹窗教学。**

| 教学点 | 载体 |
|---|---|
| 获得初始装备 | 沿途从工具柜、装备架拾取——**卡牌 = 你的装备** |
| 基础伤害牌 | 第 1 场：眷族·游体 |
| 护盾机制 | 第 2 场：教"格挡先于伤害结算" |
| **回声连击** | 第 3 场：教"交替打出工程与异化，伤害成倍" |
| 隔离值 | 第一次使用异化牌时，屏幕边缘出现青色纹路 |

> **节奏铁律**：每场只教一个概念，下一场立刻复习。**绝不在一场里塞两个新概念。**

### 4.4 通讯区：联系妹妹 `[锁定]`

| 节拍 | 内容 |
|---|---|
| 接通 | 主角联系上妹妹。**她还活着，位置暂时安全** |
| 情报 | 得知地表部分情况——但信息零碎、不可靠 |
| 中断 | 通讯因故中断（**原因待定**） |
| 情绪 | 主角微微放下心，但**玩家会隐隐不安：中断得太巧了** |

### 4.5 核心区：新手村 `[锁定]`

空间站最中心（或最顶层）的安全区，**本作的"家"**。每次爬塔回来都回到这里。

### 4.6 本期范围：只做第一阶段 `[锁定]`

**不规划第二到第四个阶段。** 开场 + 教程 + 核心区 + 第一层塔 + 第一个 BOSS 的内容量已经足够吃掉全部开发时间。

第一阶段 = **生活区 / 居住舱**（感染程度：轻度，几条走廊出现黏液）

## 5. ★ 卡牌体系：三类卡 `[锁定]`

### 5.1 三类归属

| 类别 | 归属标签 | 特点 | 初始解锁 |
|---|---|---|---|
| **工程卡** | 规程 | 稳定、费用低、伤害平。来源是空间站设备与工具 | ✅ **初始就有** |
| **异化卡** | 变异 | 伤害高、有额外效果，**代价是隔离值**。来源是星之黏块带来的眷族组织 | ✅ **初始就有** |
| **回复卡** | 中立 | 治疗、清除隔离值、抽牌。不参与连击也不打断 | ✅ **初始就有** |

> **核心张力不变**：回声连击要求你在**工程 ↔ 异化**之间交替。
> **但每次交替都必须打出异化牌 → 每次连击都在推高隔离值。**

### 5.2 第一阶段通关奖励 `[锁定]`

**击败第一个 BOSS 后：扩充「异化卡」与「回复卡」的卡池。**

| 奖励 | 内容 |
|---|---|
| **新卡组** | 解锁**克苏鲁风（异化）卡组**的完整卡池 |
| 场景解锁 | **生物实验室**（空间站的实验区） |
| 卡池拓展 | 异化卡 + 回复卡 大量新增卡牌进入掉落池 |

> **为什么先扩这两类**：工程卡是"安全牌"，异化卡是"力量牌"，回复卡是"止损牌"。
> 玩家在阶段 1 只会用最朴素的版本；阶段 1 通关后，**游戏才真正开始给玩家构筑的自由度**。

### 5.3 现有卡牌（M0 已实现，19 张）

| 类别 | 卡牌 |
|---|---|
| **工程（规程）** | 校准射击、精准打击、力场护罩、框架分析、超频运转 |
| **异化（变异）** | 撕裂、寄生孢子、血肉重塑、深渊凝视、献祭之血 |
| **回复（中立）** | 应急医疗、逻辑锁 |

**卡面美术已完成**（Aseprite 管线，32×32 像素画 + 精灵表 + 自动上色）。

## 6. 核心机制（已实现）

### 6.1 回声连击

- 交替打出**工程 ↔ 异化** → 连击 +1 → 伤害倍率提升（1.0 / 1.15 / 1.30 / 1.50 / 1.75 / 2.0）
- 打出同归属 → 连击清零；回复卡不参与也不打断

### 6.2 隔离值（0–10）

| 阈值 | 名称 | 效果 |
|---|---|---|
| 3 | 皮下蔓延 | 手牌随机 1 张被异化（费用 −1，打出时隔离再 +1） |
| 6 | 组织共生 | 每回合 +1 力量，但每回合结束失去 2 生命 |
| 8 | 意识让渡 | 异化卡费用 −1，但每回合随机弃 1 张牌（**你的手不听话了**） |
| 10 | **同化** | 你不死。你变成它们的一员——**算作通关** |

### 6.3 遗物 / 装备 `[待设计]`

永久生效的被动效果。第一期先做 6–8 个基础遗物即可。

## 7. NPC 体系

**设计三铁律**：① 每个 NPC 必须有功能 ② 随进度变化 ③ 每人有一次"最后一次对话"。

| NPC | 身份 | 功能 | 性格方向 |
|---|---|---|---|
| **叶霜** | 20 多岁·生物学家 | **升级卡牌 / 解析眷族** | 救过主角的人。冷静、爱观察、说话太准。**她自己也在被感染，瞒着主角** |
| **老吴** | 40 多岁·工程师 | **角色等级 / 装备变更** | 老油条，嘴上不认输，实际最怕死。会修一切，除了自己的问题 |
| **小周** | 20 多岁·通讯员 | **解锁牌组 / 装扮更换** | 全站唯一还在联系地球的人。抱着家人照片的平板，从不给别人看 |
| **神印** | 非人 | **精神影响源 / 真相提供者** | 它不说话，但你会"听"到它。它照出的是你自己的内疚 |

> **`[建议]` 结构性设计**：主角每次死亡回到核心区，**NPC 会稍微变化**。
> 不是他们受伤了——是**主角自己感染加深了，看到的东西变了**。
> 同一个 NPC、同样的台词，第五次回来时，玩家会注意到她皮肤下面也有东西在动。
