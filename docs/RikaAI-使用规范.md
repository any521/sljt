# Rika AI 使用规范（项目参考）

> 来源：Rika AI 官方手册
> 用途：**凡是要生成人物像素美术（尤其是需要动画的），一律按本规范来。**
> 本文档是《阿卡姆号》项目的动画生产流程基准。

---

## 一、Rika AI 是干什么的

**输入：一张静态像素图 → 输出：一段动画序列帧**

它**不是生图工具**，它是**动画生成工具**。
所以流程是：

```
第 1 步：先用别的工具（GPT/豆包）生成【静态像素图】
第 2 步：把静态图丢进 Rika AI → 得到【动画序列帧】
第 3 步：导出序列帧 → 在 Aseprite 里精修 → 接入游戏
```

**关键认知：我们不需要在提示词里描述动画帧了。**
提示词只需要产出**一张合格的静态图**，动画交给 Rika。

---

## 二、★ 静态图的硬性要求（写提示词时必须满足）

这是我以前一直写错的地方。喂给 Rika 的图必须符合：

| 要求 | 规格 | 说明 |
|---|---|---|
| **分辨率** | **64×64 / 128×128 / 256×256** | 三选一，其他尺寸不行 |
| **朝向** | **角色必须面朝右侧** | 朝向左边要手动开 FLIP 开关 |
| **留边** | **角色不能填满整个画布** | 要和图像边缘保持距离，否则效果差 |
| **背景** | 透明 或 纯色 | 两种都行 |
| **帧数** | 只需 **1 张静态图** | 不是序列帧，不是多帧并排 |

### 2.1 对我们项目的具体影响

| 资产 | 建议输入尺寸 | 理由 |
|---|---|---|
| **主角小人儿** | **64×64** | 游戏内就是这个尺寸，直接对应 |
| **叶霜小人儿** | 64×64 | 同上 |
| **普通眷族** | 64×64 | 同上 |
| **精英/BOSS 眷族** | **128×128** | 体型更大，需要更多细节 |

### 2.2 提示词里必须写的话

```
角色面朝右侧。
角色占画面 70%，四周留出空间，不要填满画布。
分辨率 64x64（或 128x128）。
```

**这三句以后每张静态图提示词都要有。**

## 三、Rika AI 的参数设置

### 3.1 生成前要设的参数

| 参数 | 设什么 | 说明 |
|---|---|---|
| **动作类型** | 见 §3.3 | 选预期的动作 |
| **像素尺寸** | **必须与你的像素格子尺寸匹配** | 这是个关键参数，填错会糊 |
| **提示词** | 见 §4 | 有默认值，可自己写 |
| **LOOP** | 待机/行走 → **开**；攻击/受击 → 关 | 无缝循环 |
| **模型强度 Strength** | 默认 **0.8** | 见 §3.4 |

### 3.2 高级控制

| 功能 | 用途 |
|---|---|
| **EXPAND → 上传自定义关键帧** | 可以控制动画的中间姿态 |
| **MID IMAGE** | 自定义中间帧 |
| **FRAMES** | 帧数。**用 MID IMAGE 时建议配合 16 帧**，过渡更平滑 |
| **SEED / FIX** | 固定种子。**动作满意时记下种子，后续生成保持一致** |

### 3.3 动作类型的注意点

| 动作 | 默认行为 | 注意 |
|---|---|---|
| **ATTACK** | **默认是"近战武器挥砍"** | 想做成别的攻击（如射击），要**把强度降到 0.3** |
| **DEFEATED** | 复杂动画，需要调参数 | |
| ATTACK 帧数 | **默认 16 帧** | **不要描述 16 帧内做不完的复杂动作** |

### 3.4 模型强度 Strength 怎么调

| 强度 | 效果 |
|---|---|
| **0.8（默认）** | 动画风格最统一、最一致 —— **大多数情况用这个** |
| **0.3** | 更遵循提示词，但质量可能不稳定 —— **用于射击类攻击等特殊动作** |

> 记住这条：**强度越高越统一，越低越听话但越不稳。**

## 四、提示词编写蓝图

### 4.1 官方给的句式

```
a [character description] uses [his/her/its] [weapon description] to perform a [attack description].
```

示例：
- `A female knight raises her sword to perform a powerful slash attack forward.`
- `A warrior points her pistol forward to shoot a bullet.` （强度调 0.3）

**要点：武器描述要详细**，这有助于动画全过程中保持武器一致。

### 4.2 我们的用法

Rika 的提示词是**英文、面向动作**的。所以流程要拆成两段：

| 阶段 | 工具 | 提示词语言 | 内容 |
|---|---|---|---|
| 生静态图 | GPT / 豆包 | 中文为主 | 角色外观、服装、配色、构图 |
| 生成动画 | **Rika AI** | **英文** | **动作描述**（见下） |

### 4.3 各角色/动作的 Rika 提示词

**沈越 · 待机**
```
A male space station operator in a dark blue-grey uniform stands idle,
breathing calmly, arms relaxed at his sides.
```

**沈越 · 行走**
```
A male space station operator in a dark blue-grey uniform walks forward
at a steady pace, arms swinging naturally.
```

**沈越 · 攻击（右爪挥击）**
```
A male operator swings his mutated purple tentacle arm forward
in a slashing attack.
```
> 注意：这是"挥砍"，符合 ATTACK 默认行为，强度保持 0.8。

**沈越 · 受击**
```
A male operator is struck and recoils backward, raising one arm to guard.
```

**叶霜 · 待机**
```
A female scientist in a white coat stands idle with both hands in her
pockets, breathing calmly.
```

**叶霜 · 行走**
```
A female scientist in a white coat walks forward holding a clipboard.
```

**眷族 · 待机**
```
A creature made of wet purple organic tissue pulses and writhes slowly
in place.
```

## 五、生成后的流程

### 5.1 内置编辑器（初步编辑）

| 功能 | 用途 |
|---|---|
| **背景去除** | 一键识别并清除背景色 |
| **画笔 / 橡皮擦** | 逐像素编辑，修正生成瑕疵 |
| **魔棒工具** | 快速选中相似颜色区域并删除 |
| **背景亮暗切换** | 检查动画在不同背景下的表现 |
| **帧选择** | 勾选剔除不理想的单帧 |
| **导出** | 动图 或 带透明通道的序列帧 |

**快捷键**：
| 键 | 功能 |
|---|---|
| `Ctrl + S` | 保存到本地浏览器缓存 |
| `Ctrl + Z / Y` | 撤销 / 重做 |
| `Ctrl + 拖拽` | 移动画布 |
| 滚轮 | 缩放画布 |
| `Q + 点击` | 快速取色 |

### 5.2 官方明确的限制

> **"此编辑器被设计为对动画的初步编辑。"**
> 复杂重绘或特效，**导出序列帧后用 Aseprite 处理**。

**所以我们的流程是**：
```
Rika 生成 → Rika 编辑器粗修（去背景、剔坏帧）
         → 导出序列帧
         → Aseprite 精修（量化色板、对齐、修正）
         → 接入 Godot
```

## 六、成本

| 项 | 消耗 |
|---|---|
| **生成一次** | **5 积分** |
| 编辑器 | 免费 |
| 导出 | 免费 |

> 生成 1–5 分钟，取决于复杂度和排队。

**成本提示**：5 积分一次不贵，但**不要浪费在参数没调好的图上**。先确认静态图合格再进 Rika。

## 七、商用许可（重要）

**生成的像素动画可以商用**，作为游戏素材或数字资产使用。

**但有一个限制**：

> 如果你**直接把生成结果二次售卖**（例如作为独立素材包出售），
> 必须在显著位置标明出处（例如：使用 Rika AI 生成）。

**对我们的影响**：
- 用在自己的游戏里 → ✅ 没问题，不需要标注
- 打包成素材包卖 → ❌ 需要标注，而且我们不会这么做

## 八、★ 以后的固定工作流

**每次要生成人物像素美术时，一律按这五步：**

| 步骤 | 做什么 | 工具 |
|---|---|---|
| **1** | 写**静态图**提示词：角色外观 + 面朝右 + 留边 + 指定分辨率 | 中文，给 GPT/豆包 |
| **2** | 生成静态图，确认合格（朝向对、留边够、尺寸对） | GPT / 豆包 |
| **3** | 写**动作**提示词（英文，按 §4.1 蓝图） | 给 Rika AI |
| **4** | Rika 生成动画，参数按 §3 设置 | Rika AI |
| **5** | 导出序列帧 → Aseprite 精修 → 接入游戏 | Aseprite / Godot |

### 写提示词时的检查清单

**静态图提示词必须包含：**
- [ ] 角色外观（发型、脸、服装、配色）
- [ ] **面朝右侧**
- [ ] **角色占画面 70%，四周留边**
- [ ] **分辨率（64×64 或 128×128）**
- [ ] 纯色或透明背景

**动作提示词必须包含：**
- [ ] 英文
- [ ] 按 `a [角色] uses [武器] to perform a [动作]` 的句式
- [ ] 武器/肢体描述详细
- [ ] 动作在 16 帧内能完成（攻击类）

### 参数检查清单

- [ ] 像素尺寸 = 静态图的像素格子尺寸
- [ ] LOOP：待机/行走开，攻击/受击关
- [ ] Strength：默认 0.8；射击类特殊动作降到 0.3
- [ ] 满意的结果**记下 SEED**，后续保持一致
