## 0. 通用规范（每条提示词都要带）

### 0.1 通用前缀（复制到每条提示词最前面）

像素游戏 UI 素材，复古像素美术风格，Aseprite 硬边像素质感，有限调色板，
清晰锐利的方块边缘，无抗锯齿，无模糊，无平滑渐变，无柔化阴影，无噪点，
无文字，无水印，无签名，无外边框，无投影，无透视。
**背景必须完全透明**；若工具不支持透明通道，请用纯品红 #FF00FF 满底，不要用白底。

### 0.2 通用后缀（生成尺寸与像素粒度）

画布宽高必须是「目标美术尺寸 × 4」；每个美术像素在画布上占 4×4 的纯色方块；
所有边缘落在 4 像素的整数倍上；输出 PNG（不要 JPEG）。
暗部禁止纯黑 #000000。

### 0.3 锁定色板（只能用这些）

| 用途 | 色值 |
|---|---|
| 最深阴影 / 外描边 | #0A0E14 / #1A0818（异化） |
| 面板底 / 暗部 | #0B0E14 / #111620 |
| 金属暗面 / 结构 | #1E3A52 |
| 金属受光 / 主色 | #3A82B2 |
| 屏幕光 / 亮部 | #6BC7FF |
| 镜面高光 | #B2E8FF |
| 警示 / 暖色 | #E8A830 · #FFDC82 |
| 危险 / 过载 | #D64440 |
| 升级金三阶 | #70581C · #D6B046 · #FFE08C |
| 异化系 | #48123A · #8C2A70 · #C7479E · #FF9EDC · #F0F6FA |
| 文本 | #E0E8F0（主）· #8592A0（次）· 面板描边 #2A303C |

### 0.4 光照与两条路线

- 工程系（UI / 舱体 / 规程）：单一主光源**左上**，硬阴影，暗部用 #111620；
- 异化系（感染 / 血肉 / 异化卡面）：**自发光**，无明确主光源，边缘必须不规则；
- **UI 永远是工程系冷青**（哪怕内容物是异化系）——这条是硬约束。

## 1. B4 · 战斗 HUD 素材

### 1.1 面板九宫格（通用容器）

- 美术 32×32（九宫格边距 12px）→ 屏上 128×128 拉伸使用
- 生成画布：128×128（4 倍）

提示词（接通用前缀/后缀）：

科幻空间站控制台面板的金属底板，方形，边角有内嵌的直角加固块与两粒螺栓，
四边是 2 像素亮青描边（#3A82B2）加 1 像素深色内衬（#0A0E14），
板面为哑光深灰蓝（#111620），表面有极轻的使用划痕（1–2 像素浅色短线，断续），
四角允许 1–2 像素锈斑，左上受光、右下压暗，中心区域干净无装饰（要被九宫格拉伸）。

### 1.2 按钮四态

- 美术 48×20 → 屏上 192×80；出 4 张：常态 / 悬停 / 按下 / 禁用

提示词：

科幻控制台按钮的金属面板，长条形，四边圆角直角混合的硬边造型，
【常态】边框 #3A82B2、内部 #111620、上缘一道亮青高光；
【悬停】整体提亮一档，边框改 #6BC7FF 并向外扩 1 像素辉光；
【按下】整体压暗一档，上缘高光消失、下缘出现一道暗影；
【禁用】整体去饱和为 #2A303C 灰，边框变暗。
四态结构必须完全一致，只改明暗与颜色。

### 1.3 能量球

- 美术 32×32 → 屏上 128×128

提示词：

科幻能量容器的圆形指示球，外圈是一圈带缺口的金属环（#1E3A52 暗面 + #3A82B2 受光面），
环上有 4 处等距的加固扣件，环内是发光的青色能量核心（#6BC7FF 中心、#B2E8FF 最亮点），
核心向内有 3 层递减的辉光扩散（离散像素，不是模糊），
底部有一枚小型的刻度标记。整体左右对称，左上受光。

### 1.4 数值条（血条 / 格挡 / 隔离值）

- 条体 8×8 可横向平铺；端点装饰 8×12 两张

提示词：

科幻仪表的横向刻度条：外层金属槽（#1E3A52 描边 + #0B0E14 内槽），
内槽里是平整的纯色填充面（不带渐变，便于程序染色），
填充面上下各留 1 像素暗边以体现凹陷；
端点装饰是两枚小型金属卡扣，左端带一个朝右的箭头缺口，右端为其镜像。

### 1.5 意图图标组（12×12 × 9 个）

- 同一位图内 9 个图标并排；美术 12×12 → 屏上 48×48

提示词：

九个科幻风格的危险提示图标，横向等距排列在同一位图上，每个都是 12×12 的像素图形，
依次为：小剑（低伤害）、大剑（中伤害）、弯刀、屠刀、斧头、镰刀（依次递增的伤害档位），
盾牌（防御）、绿色旋涡（弱化效果）、紫色旋涡（强力弱化效果）；
武器类用金属灰白（#E0E8F0）配 #3A82B2 高光，盾牌用 #6BC7FF，旋涡用 #46B46E 与 #C7479E；
每个图标中心对齐，风格统一为克制的工业符号，不要卡通感。

### 1.6 状态图标组（12×12 × 16 个）

提示词：

十六个科幻状态图标并排在同一张位图上，每个 12×12，
依次为：力量（向上的拳/箭头）、敏捷（轻足）、易伤（裂纹盾）、虚弱（下垂箭头）、
中毒（滴落液滴）、脆弱（碎骨）、荆棘（尖刺环）、人工制品（六边形护符）、
屏障（叠层板）、金属化（铆钉板）、再生（循环箭头）、束缚（锁链）、
缠绕（藤状螺旋）、空洞（空环）、燃血（血滴火苗）、隔离（断裂的舱门符号）；
统一单色（#E0E8F0）加一处 #3A82B2 高光，只有弱化类允许用 #D64440 或 #C7479E。

### 1.7 牌堆与功能区图标（16×16 × 5）

提示词：

五个科幻图标并排，每个 16×16：抽牌堆（叠起的卡背）、弃牌堆（向下箭头与卡背）、
消耗堆（燃烧成灰的卡背）、查看牌堆（放大镜与卡片）、结束回合（向右的实心箭头）；
金属灰蓝配色，1 像素暗描边保证在深色背景上可辨认。

工程系模板：

## 7. 交付与接入流程（生成方与开发方的分工）

1. **你**：按提示词生成 PNG，**保持透明底**（或品红底），按「资产名_序号.png」命名；
2. **我**：跑 tools/ 下的管线 —— 1/8 或 1/4 **最近邻降采样**（保留像素网格）→ 品红/白底**软抠图** → 按网格**切片** → 接入预制体；
3. **校验**：像素粒度是否整数倍、色板是否越界、alpha 并集包围盒是否合理（不看画布尺寸，看真实内容边界）；
4. **过目**：按美术基调 §7 —— **先给制作人看，通过后才进游戏**。

### 常见坑（都踩过）

- ❌ 白底不透明 → 画出来是一块白片（已用软抠图解决，但品红底更好抠）；
- ❌ 2048 级大图直接缩到屏幕尺寸 → 像素格糊掉（必须先最近邻降采样）；
- ❌ 同一张位图里图标间距不是整数倍 → 切片后错位；
- ❌ 用了色板外的颜色 → 回炉；
- ❌ 序列帧每帧角色位置不一致 → 播放时会抖（对齐脚底基线）。
